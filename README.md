## Rooms terminées (TryHackMe)

**Offensive Security Intro**
J'ai appris la différence entre la sécurité offensive (penser comme un attaquant pour trouver les failles) et la sécurité défensive (protéger et surveiller). J'ai aussi compris qu'une page d'administration doit demander une connexion : cacher une page ne suffit pas.

**Operation Signal**
J'ai utilisé un scanner de répertoires pour trouver des pages cachées sur un site. Une page sensible contenait des identifiants, ce qui m'a permis de me connecter et de trouver le flag. J'ai compris qu'un fichier oublié peut suffire à compromettre un site.
